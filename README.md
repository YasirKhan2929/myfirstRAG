# My First RAG Chatbot

An interactive Retrieval-Augmented Generation (RAG) chatbot built with Python, Streamlit, Sentence Transformers, and Qwen 2.5. The chatbot answers questions using information retrieved from a local store document.

## Project Overview

This project demonstrates how to build a simple RAG application that combines semantic search with a Large Language Model (LLM).

Users can ask questions through a Streamlit web interface. The system retrieves relevant information from the store document and passes it to the language model to generate an answer.

When the retrieved information is insufficient, the system attempts to respond with:

> I don't know based on the available information.

## Features

- Interactive chatbot interface built with Streamlit.
- Document loading from a local text file.
- Text chunking for document processing.
- Semantic search using Sentence Transformers.
- Text embeddings generated by `all-MiniLM-L6-v2`.
- Similarity-based retrieval using cosine similarity.
- Answer generation using Qwen 2.5 0.5B Instruct.
- Basic safeguards against unsupported answers.
- Expandable section to inspect retrieved context and similarity scores.
- Automated tests for the retrieval component.

## Architecture

The application follows this workflow:

```text
Store Document
      |
      v
Document Loading
      |
      v
Text Chunking
      |
      v
Embedding Generation
      |
      v
Semantic Retrieval <--- User Question
      |
      v
Similarity Threshold Check
      |
      v
Relevant Context
      |
      v
Qwen Language Model
      |
      v
Generated Answer
      |
      v
Streamlit Chat Interface
```

If no retrieved chunk passes the configured similarity threshold, the system returns the unknown-information response without calling the language model.

## Example Knowledge Base

The chatbot's source document contains information about:

- Products: laptops, desktop computers, phones, and accessories.
- Product suitability: work, study, and entertainment.
- Returns: eligible products can be returned within 7 days, subject to the return policy.
- Delivery: standard delivery usually takes 3–5 business days.
- Payments: credit card and cash on delivery.

The chatbot should not invent a store address or shipping policy that is absent from the document.

## Setup and Installation

### Prerequisites

- Python installed on your computer.
- Git installed if you want to clone the repository.
- An internet connection to download the models on the first run.
- Sufficient RAM or GPU memory to run the language model.

### 1. Clone the repository

```bash
git clone https://github.com/YasirKhan2929/myfirstRAG.git
cd myfirstRAG
```


### 2. Create a virtual environment

On Windows PowerShell:

```powershell
python -m venv .venv
```

### 3. Install dependencies

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 4. Launch the chatbot

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Streamlit will provide a local URL, usually:

`http://localhost:8501`

Open that address in your browser to interact with the chatbot.

The first launch downloads the embedding and language models if they are not already cached. Model loading and answer generation may be slower on a CPU.

## Example Questions

Try asking:

- What does your store sell?
- How long is the return period?
- How long does standard delivery take?
- What payment methods are accepted?
- Do you offer free shipping?
- What is your store's address?

Questions supported by the document should receive relevant answers. Questions requiring information absent from the document should receive the unknown-information response.

## Run Automated Tests

Run the retrieval tests from the project directory:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_rag.py -v
```

These tests check that relevant document information is retrieved and that similarity scores are returned in the expected format.

## Limitations

- The application currently uses a small, fixed store document.
- Retrieval uses a basic similarity threshold that may need tuning.
- Similarity scores do not guarantee that the retrieved text contains the complete answer.
- The LLM can still generate unsupported answers despite the prompt instructions.
- Current automated tests focus on retrieval rather than fully evaluating generated answers.
- The application does not yet use a dedicated vector database.
- Model performance depends on available hardware.
